# KriioWorks-public-assets

Shared public icons and image assets for KriioWorks apps, web apps, and websites. This repository is separate from application source code and private data.

## Public-data boundary

- Everything committed here is public, including Git history.
- Never upload receipts, financial records, backups, credentials, private screenshots, personal documents, or identifying photo metadata.
- Upload only intentionally public assets you own or have permission to distribute. Record third-party attribution and license terms alongside those assets.
- No blanket license is selected; public visibility does not grant unrestricted reuse rights.

## Organization

Use a folder per project (for example `ledger/`) and `shared/` for reusable assets. Create these folders when adding their first asset.

Use lowercase filenames and version suffixes such as `wallet-icon-v1.png`. Optimize images before uploading. Prefer SVG for vector artwork and PNG/WebP for raster images. Icons needing PNG URLs should use PNG. Do not rename or delete assets already referenced by deployed apps; publish a new version instead.

## Direct URLs

Use GitHub Pages URLs once Pages is enabled:

`https://asrulnasirudin.github.io/KriioWorks-public-assets/<folder>/<filename>`

Alternatively, use a raw-file URL:

`https://raw.githubusercontent.com/asrulnasirudin/KriioWorks-public-assets/main/<folder>/<filename>`

These are URL templates, not existing image files. Do not use GitHub `/blob/` page links as image URLs. GitHub may cache updates; versioned filenames avoid stale icons.

This is a small public asset library, not a backup service or unlimited image CDN. GitHub hosting limits and usage policies apply.
